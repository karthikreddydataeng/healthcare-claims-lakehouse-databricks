# HIPAA-Safe Portfolio Design

## Purpose

This document explains how the healthcare claims lakehouse project is designed safely for portfolio use.

## Data Safety Approach

This project does not use real patient data, member data, claim files, provider data, or production healthcare records.

All examples are synthetic and created only to demonstrate data engineering patterns.

## What Is Not Included

- PHI
- PII
- Patient names
- Real member IDs
- Real claim IDs
- Real provider information
- Employer-owned code
- Production credentials
- Internal architecture diagrams

## What Is Demonstrated

- Healthcare claims processing pattern
- Lakehouse architecture
- Data quality validation
- Metadata cataloging
- Delta Lake table design
- Analytics-ready data preparation

## Why This Matters

Healthcare data engineering requires careful handling of sensitive information. This project shows technical understanding while keeping the implementation safe, synthetic, and portfolio appropriate.
